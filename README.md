# DSA ki SOCH

**Solution nahi, soch sikhaenge.**

E-Skills ki DSA video series ka code: har episode ke solutions **Python, JavaScript aur C++** mein, tests ke saath.

Har problem 4 steps mein solve hoti hai:

- **S – Samjho:** problem apne shabdon mein, examples aur edge cases
- **O – Obvious:** pehle brute force
- **C – Chokepoint:** time kahan waste ho raha hai
- **H – Hack:** konsa pattern waste hataega → optimal solution

Zaroorat: sirf Python basics.
